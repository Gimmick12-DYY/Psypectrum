# GoEmotions → Hue Mapping

This repository uses a color palette for GoEmotions where warmer hues correspond to more positive valence and colder hues correspond to more negative valence. Hues are assigned deterministically from a heuristic valence score in \[-1, 1].

Mapping formula:
- Warm anchor (positive): `POS_HUE_DEG = 40°` (orange-ish)
- Cold anchor (negative): `NEG_HUE_DEG = 220°` (blue-ish)
- Given valence `v` in \[-1, 1], hue is `h = POS_HUE_DEG + (NEG_HUE_DEG - POS_HUE_DEG) * ((1 - v) / 2)`

Notes:
- The mapping is linear in valence; you can adjust `POS_HUE_DEG`, `NEG_HUE_DEG`, or per-label valence to reshape the palette.
- We will convert these hues to unit vectors (sin, cos) in the model to avoid wrap-around discontinuities.
